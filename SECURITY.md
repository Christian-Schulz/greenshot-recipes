# Security

If a recipe in this catalog does something harmful or something its description doesn't say (runs a program, sends
data somewhere, writes files where it shouldn't), please don't open a public issue. Report it privately with
[GitHub's private vulnerability reporting](https://github.com/greenshot/greenshot-recipes/security/advisories/new).

We remove a harmful recipe as fast as we can.

Problems in Greenshot itself belong to [greenshot/greenshot](https://github.com/greenshot/greenshot/security).
